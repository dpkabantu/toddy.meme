# server/ — TODDY Seasons server (Cloudflare Worker)

Answers only `toddy.meme/api/*`. Every other address is the static site (see `wrangler.jsonc`, `run_worker_first`).

- `index.js` — the Worker and its route list. `auth.js` — Passport routes (Google sign-in, join, profile, sign out, delete). `lib/` — helpers (crypto and cookies, usernames, Google).
- Needs these settings (never in the repository): `GOOGLE_CLIENT_ID` (a plain variable), and the secrets `GOOGLE_CLIENT_SECRET` and `ID_SALT`. `/api/health` reports yes/no for each, never the values.
- `paste/*.paste.sql` — generated by `node server/make-paste.mjs`: the same migration with no comments on one line, for pasting into the Cloudflare dashboard Console (its text box flattens line breaks). The tests check it builds the identical database.
- `migrations/NNNN_name.sql` — database changes, numbered. Never edit a migration that has been applied; add the next number. Each file must be safe to run twice (`IF NOT EXISTS`, `INSERT OR IGNORE`) and must end by recording itself in `schema_migrations`.
- Stage 3 (runs and points): `clock.js` (the TODDY night starts 13:00 UTC = 18:30 India time, the same for every game), `rules.js` (every points number, ONE versioned place, placeholders until the owner signs off), `points.js` (the arithmetic and ledger reads), `runs.js` (`POST /api/run/start`, `POST /api/run/finish`, `GET /api/me/points`), `games/` (server checks: `moon-brew.js` imports the game's own core; `full-moon.js` uses `full-moon-core.js`, a copy of the game's rules that `test/games.mjs` proves scores identically to the code inside the game).
- The games talk to the server through `games/season.js` (signed-in players only; guests send nothing). Changing a game's rules or its daily seed means the server copy must change with it, or runs will be refused as `mismatch`.
- Points are only ever added to `points_ledger`; a correction is a new negative row. Switch off all new points with `UPDATE settings SET value='0' WHERE key='points_enabled'`.
- `test/clock.mjs`, `test/games.mjs`, `test/runs.mjs` — Node tests (run in CI). `test/games-browser.mjs` — real-browser test: signed-in play, the server's replay, the dashboard, guest play (needs Playwright, run by hand, about 2 minutes).
- `test/auth.mjs` — sign-in tests with a fake Google (`node --no-warnings server/test/auth.mjs`). `test/passport-browser.mjs` — real-browser test of `/passport/` under the site's real security headers (needs Playwright, run by hand).
- `test/run.mjs` — `node server/test/run.mjs`. Uses real SQLite as a stand-in for Cloudflare D1 (needs Node 22). It does not run Cloudflare's own runtime.

Rules: no secrets in this repository (Cloudflare secrets only), no cookies in Stage 1, JSON answers are never cached, and raw scores of different games are never added together.
Seasons, games and their point settings are rows in the database, not code, so a new season or game does not need a rebuild.
